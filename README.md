# 백탑 길드 하우스 (가제)

현대 서울 청계천에 솟은 탑을 오르는 **백합(GL) 연애 시뮬레이션 × 길드 경영 × 탑 등반 RPG** (성인向).

- 기획서: [docs/GDD.md](docs/GDD.md)
- 상태: **M1 전체 골격 프로토타입** — 처음부터 엔딩까지 플레이 가능 (플레이스홀더 아트)

## 실행

```bash
npm install
npm run dev          # 전연령 빌드로 개발 서버 (http://localhost:5173)
npm run dev:adult    # 성인 빌드 (VITE_ADULT=true)
npm test             # 단위 테스트 (시스템·밸런스·1년 페이싱)
npm run e2e          # 브라우저 E2E (Playwright)
npm run build        # 릴리스 빌드 (디버그 콘솔·성인 씬 본문 제외)
npm run build:adult  # 성인 릴리스 빌드
```

## 구조

```
src/
  core/        상태 타입, 초기 상태, 난수(시드), 시간, 세이브, 조건 평가
  content/     캐릭터·스킬·아이템·적·층·시설·칭호·특전·이벤트·메신저 데이터
    scenes/    시나리오 (.scn). adult/ 는 성인 빌드에서만 번들
  systems/     순수 함수 게임 로직 (bond, schedule, economy, calendar, tower, battle, scene, events, actions)
  game/        zustand 스토어: 화면 전환과 흐름 제어
  ui/          React 화면 (허브, 스마트폰 앱, ADV, 탑, 전투, 엔딩)
  debug/       콘솔 명령, 자동 플레이 시뮬레이터 (릴리스 빌드에서 제외)
  tests/       Vitest
e2e/           Playwright
```

시나리오 작성법은 GDD §12.6, 이벤트 조건은 §12.5를 참고하세요.
